1. **`build_content_analyzer_schema(rubric_dimensions: list[dict]) -> dict`** — Convert ScoringRubric dimensions to CU fieldSchema. Each dimension becomes a "generate" field with type "object" containing score (number), strengths (array), weaknesses (array), suggestions (array). Include a `feedback_summary` string field.

2. **`build_voice_analyzer_schema(rubric_dimensions: list[dict]) -> dict`** — Voice-specific CU fieldSchema. Dimensions are voice quality aspects from rubric (or default voice dimensions: fluency, tone, pace, pronunciation). Each is "generate" with score + feedback.

3. **`async def sync_rubric_analyzers(db: AsyncSession, rubric: ScoringRubric) -> None`** — Per D-09: Create or update CU custom analyzers when rubric is saved. Uses PUT `{endpoint}/contentunderstanding/analyzers/{analyzer_id}?api-version=2025-11-01`. Stores analyzer IDs back to rubric model.
   - Content analyzer ID format: `rubric-content-{rubric.id[:8]}`
   - Voice analyzer ID format: `rubric-voice-{rubric.id[:8]}`
   - If CU endpoint not configured, log warning and skip (graceful degradation).

4. **`async def score_content_with_cu(endpoint: str, api_key: str, analyzer_id: str, transcript_json: str) -> dict`** — Per D-10/D-15: Submit transcript JSON (base64-encoded) to CU analyzer, poll until Succeeded. Returns parsed fields dict with dimension scores.
   - Uses existing submit-then-poll pattern from AzureContentUnderstandingAdapter.
   - Max 60 poll attempts at 2s intervals (120s total for scoring).
   - Per D-16: For voice sessions, transcript comes from CU re-transcription (handled by voice analyzer).

5. **`async def score_voice_with_cu(endpoint: str, api_key: str, analyzer_id: str, audio_url: str) -> dict`** — Per D-10/D-14: Submit audio URL (or base64 for local dev) to CU voice analyzer. Returns voice dimension scores + transcript.

6. **`def merge_scores(content_scores: dict, voice_scores: dict | None, content_weight: int, voice_weight: int) -> dict`** — Per D-11: Layered merge. Calculates content total, voice total (if present), then weighted combination. Per D-13: if voice_scores is None, final score = content only (100% weight).
   - Returns: `{"overall_score": float, "content_total": float, "voice_total": float | None, "dimensions": list, "feedback_summary": str}`

7. **`async def score_session_with_cu(db: AsyncSession, session_id: str) -> dict`** — Top-level orchestration: loads session, determines mode (text vs voice per D-13/D-14), gets rubric + analyzer IDs, calls content scorer (always) + voice scorer (if audio_url exists), merges results.
   - Falls back to mock scoring if CU endpoint not configured (preserve existing dev experience).

Key implementation notes:
- Use `httpx.AsyncClient` with timeout=30s for individual requests
- Use `Ocp-Apim-Subscription-Key` header (matching existing adapter)
- api-version=2025-11-01 (matching existing adapter)
- For content scoring input: encode transcript JSON as base64, submit as `{"inputs": [{"base64Source": "..."}]}`
- For voice scoring input: use `{"inputs": [{"url": "audio_blob_url"}]}` if URL is accessible, else base64 fallback
- Log all CU API calls at INFO level for audit
- Return structured dict compatible with existing ScoreDetail save pattern

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend → Azure CU API | API key sent via header to external service |
| CU response → scoring data | Parsed JSON from CU influences user-visible scores |
| Audio URL → CU | URL passed to CU for analysis must be valid and controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-07 | Information Disclosure | CU API key in requests | mitigate | API key from encrypted config_service (existing Fernet encryption); httpx uses HTTPS only |
| T-24-08 | Tampering | CU response manipulation | accept | CU is Azure first-party service; TLS ensures integrity in transit |
| T-24-09 | Denial of Service | CU polling timeout | mitigate | Bounded polling (60 attempts x 2s = 120s max); asyncio.create_task for background execution |
| T-24-10 | Tampering | Audio URL pointing to malicious content | mitigate | Validate audio_url starts with configured Azure storage endpoint or is local storage path |
| T-24-11 | Elevation of Privilege | Non-admin triggering analyzer creation | mitigate | sync_rubric_analyzers only called from rubric_service (admin-only endpoints) |
</threat_model>
