<objective>

Purpose: Satisfy AVUI-02 ("旧 coach 功能导航入口通过 feature flag 隐藏，代码与路由保留，现有测试不破坏") without touching access control, without deleting any code, and without breaking the existing Playwright/pytest/vitest suites.
Output: New `feature_legacy_coach_nav_enabled` flag wired end-to-end; `UserLayout` gated at both render sites; backend + frontend unit tests updated to cover both flag states; full E2E regression proven against the 35-01 baseline.
</objective>
