```python
"""WebRTC session configuration service for Azure Voice Live.

Constructs the signaling WebSocket URL (/voice-live/realtime/calls endpoint)
and exchanges API key for bearer token for browser-safe authentication.
Audio flows directly browser-to-Azure over WebRTC — backend only brokers auth.
"""
import logging
from sqlalchemy.ext.asyncio import AsyncSession
from app.services import config_service
from app.services.agents.adapters.azure_voice_live import parse_voice_live_mode
from app.services.voice_live_service import _exchange_api_key_for_bearer_token
from app.utils.azure_endpoints import to_cognitive_services_endpoint
from app.schemas.voice_live import WebRTCSessionResponse

logger = logging.getLogger(__name__)

WEBRTC_API_VERSION = "2026-01-01-preview"

async def create_webrtc_session_config(
    db: AsyncSession,
    hcp_profile_id: str | None = None,
    vl_instance_id: str | None = None,
) -> WebRTCSessionResponse:
    """Build WebRTC session config: signaling URL + bearer token + session settings.
    
    Steps:
    1. Load Voice Live config (same as WS proxy logic)
    2. Resolve per-HCP voice/avatar settings if hcp_profile_id provided
    3. Build signaling URL with /voice-live/realtime/calls path
    4. Exchange API key for bearer token via STS
    5. Return everything frontend needs to establish WebRTC connection
    """
```

The function must:
- Load azure_voice_live config using `config_service.get_config(db, "azure_voice_live")`
- Get effective API key via `config_service.get_effective_key(db, "azure_voice_live")`
- Get effective endpoint via `config_service.get_effective_endpoint(db, "azure_voice_live")`
- Convert to cognitive services endpoint via `to_cognitive_services_endpoint()`
- Parse agent/model mode via `parse_voice_live_mode(vl_config.model_or_deployment)`
- If hcp_profile_id provided, load HCP profile for per-HCP settings (same pattern as voice_live_service.py lines 145-179)
- Build signaling URL: `wss://{endpoint_host}/voice-live/realtime/calls?api-version=2026-01-01-preview&model={model}` for model mode, or `wss://{endpoint_host}/voice-live/realtime/calls?api-version=2026-01-01-preview&agent_id={agent_id}&project_id={project_name}` for agent mode
- Exchange API key for bearer token via `_exchange_api_key_for_bearer_token(endpoint, api_key)`
- Build session_config dict with keys: `voice` (name, type), `turn_detection` (type), `input_audio_noise_reduction`, `input_audio_echo_cancellation`, `instructions`
- Set `avatar_warning = "Avatar (digital human) is not supported with WebRTC audio transport in preview."` always (Azure limitation)
- Raise ValueError with descriptive message if Voice Live not configured

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> POST /webrtc/session | Authenticated user requests WebRTC session credentials |
| backend -> Azure STS | API key exchanged for short-lived bearer token |
| browser -> Azure WebSocket | Frontend connects to Azure signaling with bearer token |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-01 | Elevation of Privilege | POST /webrtc/session | mitigate | Endpoint requires JWT auth via `Depends(get_current_user)` — same pattern as existing /token endpoint |
| T-26-02 | Information Disclosure | API key in response | mitigate | Never return raw API key; exchange for 10-min bearer token via STS. Test verifies key absence from response. |
| T-26-03 | Information Disclosure | Bearer token lifetime | accept | STS tokens expire in 10 minutes — acceptable for session-scoped use. Azure enforces this server-side. |
| T-26-04 | Spoofing | Signaling URL manipulation | mitigate | Backend constructs full signaling URL server-side; frontend receives pre-built URL, cannot alter the base endpoint. |
| T-26-05 | Tampering | session_config injection | accept | session_config is built server-side from DB config; frontend only reads, does not influence URL params or auth. |
</threat_model>
