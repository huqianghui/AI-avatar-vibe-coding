## Spacing Scale

Declared values (must be multiples of 4), matching the project's existing Tailwind v4 scale:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps inside citation cards, badge padding |
| sm | 8px | Gap between stacked citation cards, gap between mic button and send button |
| md | 16px | Default card/dialog padding, gap between input field and mic button |
| lg | 24px | Page-level gutter (gap between avatar column and sources panel on desktop), dialog padding |
| xl | 32px | Empty-state vertical padding inside sources panel |
| 2xl | 48px | (reserved — not used by this phase's new components) |
| 3xl | 64px | (reserved — not used by this phase's new components) |

Exceptions:
- **Mic button touch target: 56px** (`h-14 w-14`) — already established in `voice-controls.tsx`'s central mic button; reuse the same 56px circular target for the anonymous input bar's mic button (icon-only touch target exception, matches existing pattern).
- **Send button touch target: 44px** (`h-11 w-11`) — minimum accessible tap target for the secondary send action.
- **Bottom input bar height: 72px** (multiple of 8, not the existing 80px `voice-controls.tsx` bar — see Layout Contract below for why this phase uses a lighter, non-reused bar).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 400 (regular) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.3 |
| Display | 24px | 600 (semibold) | 1.2 |

Exactly 2 weights used across all four roles: **400 regular** (Body, Label) and **600 semibold** (Heading, Display) — this satisfies the "exactly 2 weights" contract for this phase's *new* components.

**Implementation note:** the project's global `@layer base` sets `button { font-weight: var(--font-weight-medium) }` (500). New Phase 32 components (mic button, send button, sources panel, dialogs) MUST override this with explicit `font-normal` / `font-semibold` Tailwind utility classes rather than relying on the inherited 500 weight, to keep this phase's typography to exactly the 2 declared weights.

**Usage map:**
- Body (16/400): transcript bubbles (reused from `voice-transcript.tsx`), citation card title, mic-permission dialog body copy, refusal-template message text
- Label (14/400): timestamps, citation "第 N 页" / "Page N" badge, helper/hint text under input bar, empty-state body copy
- Heading (20/600): "参考来源" / "Sources" sources-panel header, mic-permission dialog title
- Display (24/600): optional top-left brand wordmark only (this phase intentionally has no page `<h1>` — the avatar page is full-bleed per the AVUI "clean UI" direction that Phase 35 will finalize); reserve, do not invent additional uses

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` (#FFFFFF) | Page canvas, input bar background, dialog surfaces |
| Secondary (30%) | `--muted` (#F9FAFB) + existing `bg-gradient-to-b from-slate-50 to-slate-100` | Avatar backdrop (reused unchanged from `avatar-view.tsx`), sources-panel card default background, sources-panel container background, citation card border (`--border`) |
| Accent (10%) | `--primary` (#1E40AF) | **Reserved for exactly these 4 elements — nothing else:** (1) mic button idle/active state, (2) send button background, (3) citation card hover border + link text color, (4) connection-status "connected" indicator dot |
| Destructive | `--destructive` (#EF4444) | **Reserved for exactly these 2 elements:** (1) rate-limit-exceeded (429) toast accent, (2) inline retry-failure text inside the mic-permission dialog after a second denied attempt. Never used for the no-match/refusal state — a graceful refusal is expected behavior, not an error, and must render in neutral/muted tones. |

Accent reserved for: mic button, send button, citation-card hover/link color, connected-status dot. **Never** apply `--primary` broadly to all interactive elements (e.g. plain text links, secondary buttons, tab controls stay neutral/outline).

## Layout Contract

**Source of truth:** user-confirmed ASCII layout from `32-CONTEXT.md` — left large digital-human area (voice + subtitles) with a bottom input+mic bar, right fixed "参考来源" (sources) panel.

### Desktop (≥1024px)
- Two-column CSS grid: `grid-cols-[1fr_360px] gap-6` (24px gutter), full viewport height.
- Left column: `AvatarView` (reused unchanged) stacked above the new `avatar-input-bar.tsx`. Avatar area height: `h-[calc(100vh-48px-72px)]` — 48px top bar (login corner link) + 72px input bar, **not** the authenticated app's `64px` nav / `80px` voice-controls bar, because the anonymous root page has no app shell.
- Right column: `sources-panel.tsx`, `sticky top-0`, full height, `border-l border-border`, `bg-background`.

### Tablet (768–1023px)
- Same two-column grid, sources panel width narrows to `300px`.

### Mobile (<768px) and Teams Tab (narrow iframe)
- Sources panel is **not** shown as a persistent column (no room). Reuse the existing `Sheet` component (`side="bottom"`) triggered by a small pill button anchored near the input bar: `"参考来源 (N)"` / `"Sources (N)"`, where N = current citation count (0–3). Tapping opens the same `sources-panel.tsx` content inside the Sheet.
- Avatar area takes full remaining height above the input bar; input bar remains fixed at the bottom (`72px`, safe-area-aware for Teams Tab / mobile browser chrome).

### Top bar (all breakpoints)
- 48px height, transparent/background-colored, contains only: optional brand wordmark (Display 24/600, top-left) + login entry (top-right, ghost `Button` with `LogIn` icon + "登录"/"Login" label, Label size 14/400 — override base 500 weight per Typography note above).

### Do NOT reuse as-is
`voice-controls.tsx` (the dark `bg-slate-900/95` 80px bar with camera-off/end-call/keyboard-toggle/fullscreen-toggle) is designed for the **authenticated training-session** identity and is visually heavy/session-management-flavored. Build a new, lighter `avatar-input-bar.tsx`:
- White/`--background` bar, `border-t border-border`, height 72px
- Contents: `Textarea`/`Input` (auto-grow, single line default) + circular 56px mic button (reuse the state-machine logic/colors from `getMicButtonConfig` in `voice-controls.tsx` — same color tokens: `bg-primary` idle, `bg-voice-speaking` listening+pulse, `bg-voice-warning` speaking, `bg-muted-foreground` muted) + 44px send button (`bg-primary`, `ArrowUp` or `Send` lucide icon)
- No camera-off, no end-call, no keyboard-toggle, no fullscreen-toggle — this is a minimal, always-connected, no-session-chrome bar

## Interaction States (sources panel — Claude's Discretion per CONTEXT.md)

| State | Visual Treatment |
|-------|------------------|
| **Loading** (citation retrieval in flight, concurrent with agent answer) | 1–3 `Skeleton` rows, each `h-[72px] rounded-lg`, matching the final citation-card footprint — **not** a spinner (matches existing codebase convention in `avatar-view.tsx`) |
| **Populated** (1–3 citations, all fields present) | Card list, `gap-2` (8px) between cards, each card: `p-4 rounded-lg border border-border`, hover → `border-primary/40` + `bg-accent/5` (the one sanctioned accent hover use). Content: title (Body 16/600 — exception: title uses semibold within the Body-sized row for scannability, 2-line clamp), page badge (Label 14/400, muted-foreground, "第 {{n}} 页" / "Page {{n}}"), full clickable row opens URL in a new tab, trailing `ExternalLink` icon (14px, muted-foreground) |
| **Empty — session just started** (no question asked yet) | Centered, `py-8` (32px), `BookOpen` icon (32px, muted-foreground) + heading "暂无参考来源" / "No sources yet" (Label 14/600) + body "向数字人提问后，相关内容来源会显示在这里" / "Ask the avatar a question and its sources will appear here" (Label 14/400, muted-foreground) |
| **Empty — no match / refusal** (retrieval returned no full-field citation) | Same centered layout as above, **neutral tones only (never destructive/warning color)** — icon `SearchX` (32px, muted-foreground) + heading "本次未找到匹配来源" / "No matching source this time" + body "请尝试换一种问题的表述方式" / "Try rephrasing your question". Fires in lockstep with the refusal-template transcript bubble (see below). |
| **Citation strictly incomplete** (title/URL/page not all present) | That single citation is silently dropped from the array before render — never show a partial card. If all candidates are incomplete, render the "no match" empty state above, not a "no match" + partial-card mix. |

## Interaction States (avatar/voice — Claude's Discretion per CONTEXT.md)

| State | Visual Treatment |
|-------|------------------|
| **Refusal template response** | Rendered as a normal assistant transcript bubble reusing `voice-transcript.tsx` styling unchanged (`bg-muted`, rounded-2xl, left-aligned) — a graceful refusal is expected, correct behavior, not an error; no red/destructive styling |
| **Mic permission unavailable** | `Dialog` (reuse `ui/dialog.tsx`) — Title (Heading 20/600) "需要麦克风权限才能语音提问" / "Microphone access needed to ask by voice"; Body (Body 16/400) "点击「允许」并在浏览器弹窗中授予麦克风权限，即可通过语音向数字人提问。您也可以直接使用文字输入框提问。" / "Click Allow in your browser's prompt to enable voice questions. You can also type your question instead."; Primary button "重试授权" / "Try Again" (`bg-primary`); Secondary button "改用文字输入" / "Use Text Instead" (outline/ghost, closes dialog + focuses text input). On a second failed attempt: inline `text-destructive` (Label 14/400) "仍未获得麦克风权限，请检查系统/浏览器设置" / "Still no microphone access — check your OS/browser settings." Text input remains fully usable regardless of dialog state at all times. |
| **Rate limit exceeded (429)** | `sonner` toast (reuse `ui/sonner.tsx`), warning/destructive accent, "请求过于频繁，请稍候再试" / "Too many requests — please wait a moment." Input bar shows a disabled state with helper text (Label 14/400, muted-foreground) beneath it, honoring the response's `Retry-After` value: "请求过多，请 {{seconds}}s 后重试" / "Rate limited — retry in {{seconds}}s" |
| **Session silent rebuild** (30-min inactivity expiry) | No visible error on the happy path — a fresh `POST /public/avatar/session` is issued transparently. Only if rebuild itself fails, show the same connection-error tone already established in `voice.json`'s `error.connectionFailed` copy ("连接语音服务失败，请检查网络并重试" / "Failed to connect — check your network and try again"), via `sonner` toast, neutral/destructive per existing convention |
| **End session** (if surfaced at all for anonymous users — optional, Claude's discretion; recommend omitting for MVP since anonymous sessions self-expire) | If included, reuse existing `endSessionTitle`/`endSessionConfirm` Dialog copy/pattern verbatim (no new copy needed) — this is the phase's one destructive-action confirmation, already defined in `voice.json` |
