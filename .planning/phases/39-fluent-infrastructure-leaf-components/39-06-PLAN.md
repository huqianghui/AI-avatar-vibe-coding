Migrate Progress and Slider (LEAF-05) to be internally backed by Fluent UI, each committed independently (D-07). Both share the same category of risk: a numeric-contract mismatch between the codebase's existing public API (0-100 scale for Progress; array-based multi-value signature for Slider) and Fluent's internal representation (0-1 decimal scale defaulting to max=1; scalar single-value signature) -- a silent scaling or shape bug here is invisible until a specific numeric edge case is hit (Pitfall 13).
