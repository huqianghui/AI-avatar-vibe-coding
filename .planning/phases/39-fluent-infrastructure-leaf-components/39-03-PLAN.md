```ts
declare const Divider: React.FC<{

}>;
```

```ts
declare const Skeleton: React.FC<{ animation?: "pulse" | "wave"; className?: string; children?: React.ReactNode }>;
declare const SkeletonItem: React.FC<{ shape?: "rounded" | "circle" | "square"; size?: number; className?: string }>;
```
Current `skeleton.tsx` is likely a single flat `<div className={cn("animate-pulse rounded-md bg-muted", className)} />`. New internal composition: `<Skeleton className={...}><SkeletonItem className={cn("h-full w-full", className)} /></Skeleton>` -- keep the exported `Skeleton` component's call signature IDENTICAL (single component, no children required from the consumer), the `Skeleton`+`SkeletonItem` composition is purely internal.
