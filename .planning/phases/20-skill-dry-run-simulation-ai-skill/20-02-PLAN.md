Create `backend/app/services/dry_run_engine.py` implementing the simulation orchestration.

**Core function: `async def run_dry_run_simulation(dry_run_id: str) -> None`**

This is a durable background task that creates its own DB session (same pattern as skill_evaluation_service). It:

1. **Opens own AsyncSession** via `async with AsyncSessionLocal() as db:` (NOT using the request session, which may be closed)

2. **Loads the DryRun and associated Skill** with content:
   ```python
   dry_run = await db.get(DryRun, dry_run_id)
   skill = await db.get(Skill, dry_run.skill_id)
   ```

3. **Sets status to "running"**, records start time:
   ```python
   dry_run.status = "running"
   start_time = datetime.now(tz=UTC)
   await db.flush()
   ```

4. **Extracts SOP steps from skill content** using `_extract_sop_steps(skill.content)`:
   - Parse the Skill SOP markdown content
   - Find step headers matching patterns like `## Step N:`, `### N.`, numbered lists `1.`, `2.` etc.
   - Each step gets a `step_id` (e.g., "step_1", "step_2") and `step_name` (the header text)
   - Returns `list[dict]` with keys: `step_id`, `step_name`, `step_content`
   - If no SOP steps found, use the full content as a single step

5. **Builds system prompts for MR and HCP agents:**

   MR system prompt (stored as constant `_MR_SYSTEM_PROMPT`):
   ```
   You are a Medical Representative (MR) in a training simulation. Your goal is to practice selling a pharmaceutical product to a doctor (HCP).

   You must follow the SOP (Standard Operating Procedure) steps below and try to cover all of them during the conversation. Be natural, professional, and respond to the HCP's questions and objections.

   SOP Steps to follow:
   {formatted_sop_steps}

   Rules:
   - Start with a greeting and introduction
   - Follow the SOP steps in order when possible
   - Respond naturally to HCP questions/objections
   - Try to cover ALL SOP steps
   - Keep responses concise (2-4 sentences)
   - End the conversation after covering all steps or after 20 exchanges
   ```

   HCP system prompt (stored as constant `_HCP_SYSTEM_PROMPT`):
   ```
   You are a Healthcare Professional (HCP/Doctor) in a training simulation. A Medical Representative (MR) is visiting you to discuss a pharmaceutical product.

   Behave like a realistic doctor:
   - You are busy and have limited time (10-15 minutes)
   - Ask relevant clinical questions about efficacy, safety, dosing
   - Raise common objections (cost, existing treatments, guidelines)
   - Show interest when the MR presents compelling data
   - Be professional but direct
   - Keep responses concise (1-3 sentences)

   Product context from the Skill:
   {skill_name}: {skill_description}
   ```

6. **Runs the simulation loop** (max 20 turns, 10 exchanges):
   ```python
   conversation: list[dict] = []  # {"role": "mr"|"hcp", "content": str}
   sequence = 0

   for turn in range(MAX_TURNS):  # MAX_TURNS = 20
       # Determine whose turn it is (MR starts)
       current_role = "mr" if turn % 2 == 0 else "hcp"

       # Build the prompt for the current agent
       if current_role == "mr":
           response = await _call_llm(mr_system_prompt, conversation, "MR")
       else:
           response = await _call_llm(hcp_system_prompt, conversation, "HCP")

       conversation.append({"role": current_role, "content": response})

       # Annotate with SOP step matching
       matched_step = _match_sop_step(response, sop_steps, current_role)

       # Save message to DB
       msg = DryRunMessage(
           dry_run_id=dry_run_id,
           sequence_number=sequence,
           role=current_role,
           content=response,
           sop_step_id=matched_step["step_id"] if matched_step else None,
           sop_step_name=matched_step["step_name"] if matched_step else None,
       )
       db.add(msg)
       sequence += 1

       # Check for natural conversation end
       if _is_conversation_ending(response, turn):
           break

       await db.flush()
   ```

7. **Helper: `async def _call_llm(system_prompt, conversation, agent_name) -> str`**
   - Uses the same pattern as _call_agent_for_evaluation in skill_evaluation_service
   - Gets project endpoint via `get_project_endpoint(db)`
   - Creates openai client via `_get_project_client`
   - Calls `openai_client.chat.completions.create()` (NOT responses API -- use standard chat completions for flexibility)
   - Model: "gpt-4o" (hardcoded constant `DRY_RUN_MODEL = "gpt-4o"`)
   - Messages: system prompt + conversation history formatted as user/assistant alternating
   - Temperature: 0.7 for natural conversation
   - Max tokens: 300 per response
   - On exception: return a fallback message "[Agent unavailable — simulation continues]"

8. **Helper: `def _match_sop_step(message, sop_steps, role) -> dict | None`**
   - Only matches for MR messages (HCP responses don't cover SOP steps)
   - For each SOP step, check if key terms from `step_content` appear in the message
   - Uses simple keyword overlap scoring: tokenize both, count common meaningful words (>3 chars), threshold >= 2 matches
   - Returns the best-matching step or None

9. **Helper: `def _is_conversation_ending(message, turn_number) -> bool`**
   - Returns True if turn >= 18 (approaching max)
   - Returns True if message contains ending phrases: "thank you for your time", "I'll let you go", "goodbye", "see you next time", etc. (case-insensitive)

10. **Computes coverage report after simulation:**
    ```python
    coverage_map = _compute_sop_coverage(sop_steps, messages)
    issues = _identify_issues(coverage_map, sop_steps)
    score = _compute_executability_score(coverage_map, len(conversation))
    ```

    `_compute_sop_coverage(sop_steps, messages) -> list[dict]`:
    - For each SOP step, find all messages that matched it
    - Status: "covered" if >= 1 strong match, "partial" if weak match, "not_covered" if none
    - Returns list of `{"step_id", "step_name", "status", "matched_message_ids", "details"}`

    `_identify_issues(coverage_map, sop_steps) -> list[dict]`:
    - For each "not_covered" step: create error issue with suggestion
    - For each "partial" step: create warning issue with what was missing
    - Returns list of `{"severity", "step_id", "description", "suggestion"}`

    `_compute_executability_score(coverage_map, num_messages) -> int`:
    - Base score from coverage: (covered * 100 + partial * 50) / total_steps
    - Conversation quality bonus: if num_messages >= 8, add up to 10 points
    - Cap at 100

11. **Updates DryRun with results:**
    ```python
    dry_run.status = "completed"
    dry_run.executability_score = score
    dry_run.coverage_percent = round(covered * 100 / total) if total else 0
    dry_run.total_sop_steps = len(sop_steps)
    dry_run.covered_sop_steps = sum(1 for c in coverage_map if c["status"] == "covered")
    dry_run.partial_sop_steps = sum(1 for c in coverage_map if c["status"] == "partial")
    dry_run.issues_count = len(issues)
    dry_run.issues_json = json.dumps(issues, ensure_ascii=False)
    dry_run.sop_coverage_json = json.dumps(coverage_map, ensure_ascii=False)
    dry_run.duration_seconds = int((datetime.now(tz=UTC) - start_time).total_seconds())
    await db.commit()
    ```

12. **Error handling:** Wrap entire function in try/except. On failure:
    ```python
    dry_run.status = "failed"
    dry_run.error_message = str(e)[:500]
    await db.commit()
    ```
