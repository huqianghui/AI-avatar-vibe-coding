**1. `dry-run-button.tsx` — DryRunButton:**

Props: `{ skillId: string | undefined, hasContent: boolean, isNew: boolean, skillStatus: string, onDryRunCreated: (runId: string) => void }`

- Renders Button with `variant="outline"` and FlaskConical icon (from lucide-react)
- Text: `t("skill:dryRun.button")`
- Disabled when:
  - `isNew` is true (no skill ID)
  - `hasContent` is false (no SOP content)
  - `skillStatus` is "archived" or "failed" (per UI-SPEC Lifecycle Integration)
- When disabled, wrap in Tooltip with `t("skill:dryRun.tooltipDisabled")`
- On click: open Dialog (confirmation dialog per UI-SPEC):
  - Title: `t("skill:dryRun.startTitle")`
  - Description: `t("skill:dryRun.startBody")`
  - Footer: "Go Back" (outline) and "Start Simulation" (primary)
- "Start Simulation" click:
  - Uses `useCreateDryRun()` mutation
  - On success: close dialog, call `onDryRunCreated(data.id)`, toast.success
  - On error: toast.error with `t("skill:dryRun.errorStartFailed")`

**2. `dry-run-progress.tsx` — DryRunProgress:**

Props: `{ skillId: string, runId: string, onCompleted: () => void, onCancel: () => void }`

- Uses `useDryRunStatus(skillId, runId, true)` for 3s polling
- Displays:
  - Card with rounded-lg border bg-card p-6
  - Spinner icon (animate-spin) + `t("skill:dryRun.progressSimulating")` heading
  - Step counter: `t("skill:dryRun.progressStep", { current: statusData.covered_sop_steps, total: statusData.total_sop_steps })`
  - Progress bar: `<Progress value={statusData.coverage_percent ?? 0} />` with striped animation via CSS class
  - Cancel button: variant="outline" with text-destructive color, onClick opens confirm dialog
- Cancel confirmation: `t("skill:dryRun.cancelConfirm")`
- When `statusData.status === "completed"`: calls `onCompleted()` and shows toast `t("skill:dryRun.toastCompleted")`
- When `statusData.status === "failed"`: shows error banner with `t("skill:dryRun.errorRunFailed")` and retry option
- When `statusData.status === "cancelled"`: shows toast `t("skill:dryRun.toastCancelled")` and calls `onCancel()`
- aria-live="polite" on the progress container for screen readers
