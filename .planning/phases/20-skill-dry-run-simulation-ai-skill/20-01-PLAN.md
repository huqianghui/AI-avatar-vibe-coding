**Create `backend/app/schemas/dry_run.py`:**

```python
from datetime import datetime
from pydantic import BaseModel, ConfigDict

class DryRunMessageOut(BaseModel):
    id: str
    dry_run_id: str
    sequence_number: int
    role: str  # "mr" | "hcp"
    content: str
    sop_step_id: str | None
    sop_step_name: str | None
    created_at: datetime
    model_config = ConfigDict(from_attributes=True)

class SopStepCoverage(BaseModel):
    step_id: str
    step_name: str
    status: str  # "covered" | "partial" | "not_covered"
    matched_message_ids: list[str] = []
    details: str = ""

class DryRunIssue(BaseModel):
    severity: str  # "warning" | "error"
    step_id: str | None = None
    description: str
    suggestion: str = ""

class DryRunListOut(BaseModel):
    id: str
    skill_id: str
    run_number: int
    status: str
    executability_score: int | None
    coverage_percent: int | None
    total_sop_steps: int
    covered_sop_steps: int
    issues_count: int
    duration_seconds: int | None
    created_at: datetime
    model_config = ConfigDict(from_attributes=True)

class DryRunOut(DryRunListOut):
    partial_sop_steps: int
    sop_coverage: list[SopStepCoverage]  # parsed from sop_coverage_json
    issues: list[DryRunIssue]  # parsed from issues_json
    error_message: str
    messages: list[DryRunMessageOut] = []
    created_by: str
```

Note: `sop_coverage` and `issues` are parsed from JSON in the service layer, NOT directly from ORM (since ORM stores as JSON string). Use a `@classmethod` or service-layer conversion function.

**Create `backend/app/services/dry_run_service.py`:**

Functions:
- `async def create_dry_run(db: AsyncSession, skill_id: str, created_by: str) -> DryRun`: Validates skill exists and has content. Computes next `run_number` via `select(func.coalesce(func.max(DryRun.run_number), 0)).where(DryRun.skill_id == skill_id)`. Creates DryRun with status="pending". Calls `db.flush()`.
- `async def get_dry_run(db: AsyncSession, dry_run_id: str) -> DryRun | None`: Load with selectinload(DryRun.messages). Return None if not found.
- `async def get_dry_run_or_404(db: AsyncSession, dry_run_id: str) -> DryRun`: Calls get_dry_run, raises not_found if None.
- `async def list_dry_runs(db: AsyncSession, skill_id: str, page: int = 1, page_size: int = 20) -> tuple[list[DryRun], int]`: List runs for a skill, ordered by run_number DESC. Return (items, total).
- `async def cancel_dry_run(db: AsyncSession, dry_run_id: str) -> DryRun`: Sets status to "cancelled" if current status is "pending" or "running". Raises bad_request otherwise.
- `def dry_run_to_out(dry_run: DryRun) -> dict`: Parses `sop_coverage_json` and `issues_json` from JSON strings into Python objects, building the full response dict. This helper is used by the router to construct the response.

**Create `backend/app/api/dry_runs.py`:**

Router prefix: `/skills/{skill_id}/dry-runs`, tags: `["dry-runs"]`
- Dependencies: `get_db`, `require_role("admin")`

Endpoints:
- `POST /skills/{skill_id}/dry-runs` — Creates a new dry run, returns 201 with DryRunOut. Calls create_dry_run service, then kicks off background simulation (Plan 02 will implement the actual engine; for now, just return the pending dry run).
- `GET /skills/{skill_id}/dry-runs` — List dry runs for a skill with pagination (page, page_size query params). Returns PaginatedResponse with DryRunListOut items.
- `GET /skills/{skill_id}/dry-runs/{run_id}` — Get full dry run detail with messages. Returns DryRunOut.
- `POST /skills/{skill_id}/dry-runs/{run_id}/cancel` — Cancel a running/pending dry run. Returns DryRunOut.
